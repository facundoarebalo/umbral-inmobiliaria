# Umbral Inmobiliaria

Landing ficticia para una inmobiliaria, creada como proyecto de portfolio con React y Vite.

## Desarrollo

```bash
pnpm install
pnpm dev
```

## Producción

```bash
pnpm build
pnpm preview
```

La marca, propiedades y valores son ilustrativos. El formulario es una demostración y no envía información.
